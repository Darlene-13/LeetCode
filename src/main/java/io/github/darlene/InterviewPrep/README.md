# INTERVIEW PREP

This folder is organized into **focused practice days**. Each day covers one data structure or algorithmic pattern.

Some problems here also appear in other folders. That is intentional: solving the same problem again from memory builds pattern recognition and implementation fluency.

## How Each Problem Is Documented

1. What approach or pattern am I using?
2. Why does it work?
3. What am I storing?
4. What happens as I iterate?
5. What is the time complexity?
6. What is the space complexity?
7. What are the important edge cases?
