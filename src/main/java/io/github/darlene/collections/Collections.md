# COLLECTIONS FRAMEWORK IN JAVA
The java collection framework is basically a set of classes and interfaces that provided ready-made data structures to store
and manipulate groups of objects efficiently.

Java provides collection interfaces like: List, Set, Map, Queue with ready-made classes like ArrayList, HashSet, HashMap, PriorityQueue.

Therefore, we won't have to write the data handling code from scratch.


1. Provides ready to use data structures (ArrayList, HashMap, HashSet, Queue)
2. Offers instances (Collection, List, Set, Map)
3. Supports dynamic resizing, unlike arrays
4. Includes algorithms (Sorting, searching, iteration)
5. Improves code re-usability and performance by reducing boilerplate code.
