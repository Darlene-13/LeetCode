# COLLECTIONS

This folder groups my practice by the **Java Collections Framework** data structure that each problem is built around.

For background on the framework itself (what it is and why we use it), see [Collections.md](Collections.md).

## Folders

| Folder | What it contains |
| --- | --- |
| [list/](list/README.md) | `ArrayList` notes and practice, plus the `arrays`, `linkedlist` and `stack` problem folders. |
| [list/arrays/](list/arrays/README.md) | Array problems: HashMap lookups, two pointers, Boyer-Moore voting, heaps, binary search. |
| [list/linkedlist/](list/linkedlist/README.md) | Linked list problems: dummy nodes, fast/slow pointers, in-place reversal. |
| [list/stack/](list/stack/README.md) | Stack problems: bracket matching, monotonic stack, min stack. |
| [queue/](queue/README.md) | `PriorityQueue` (heap) problems. |
| [set/](set/README.md) | `HashSet` problems. |
| [map/](map/README.md) | `HashMap` problems. |

## How Each README Is Written

Each problem section answers the same questions:

1. What approach or pattern am I using?
2. What am I storing?
3. What happens as I iterate?
4. Why does it work?
5. What is the time and space complexity?
6. What are the important edge cases?
