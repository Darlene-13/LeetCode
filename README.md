# LEETCODE PRACTICE

A structured Java repository for practicing Data Structures, Algorithms, and problem-solving through repeated implementation.

The goal is not just to solve problems once, but to **understand the underlying patterns, explain the reasoning, and rebuild solutions from memory**.

Problems may appear more than once across different practice days or folders. This is intentional. Re-solving the same problem helps strengthen algorithmic thinking, pattern recognition, and implementation fluency.

### InterviewPrep

Organized into focused practice sessions based on a specific data structure or algorithmic pattern.

```text
InterviewPrep/
├── Day1Arrays/
├── Day2LinkedLists/
└── ...
```

Each problem is approached by asking:

1. What approach or pattern am I using?
2. Why does it work?
3. What am I storing?
4. What happens as I iterate?
5. What is the time complexity?
6. What is the space complexity?
7. What are the important edge cases?

The focus is on **understanding first, implementation second**.
